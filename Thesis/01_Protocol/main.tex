   \begin{abstract}
An artificial neural network is a Machine Learning model inspired by the functioning of biological neural networks. It is composed of artificial neurons (or nodes) organised into layers (input, hidden, and output), where information is processed through non-linear mathematical transformations.

The learning process of these models is carried out through training, during which data pass through the network layer by layer. In each neuron, an activation function is computed, the loss is estimated by comparing the output with the actual value, and then the backpropagation algorithm is applied to adjust the weights and biases in order to minimise this loss. This process is repeated until the loss converges.

In the traditional approach, the model is trained with an initial dataset and, upon the arrival of new information, it must be retrained from scratch using all available data. This process can be inefficient and computationally expensive, especially with large data volumes.

Incremental learning, a branch of Artificial Intelligence, allows updating the model’s knowledge without the need to retrain it completely with historical data \cite{bullinaria2009}. In this work, Artificial Neural Networks focused on handwritten digit classification will be used, employing the backpropagation algorithm in Multilayer Perceptron networks. A weight duplication strategy will be explored to simulate short- and long-term memory mechanisms, aiming to improve upon the results presented in \cite{bullinaria2009}.
\end{abstract}


  \textbf{Keywords:} Incremental Learning, Artificial Neural Networks, Digit Classification.
