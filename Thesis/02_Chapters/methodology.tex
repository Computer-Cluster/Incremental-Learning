\section{Methodology}

This work is divided into three main stages: the recreation of the base model, the implementation of an extension to the model, and the comparison of the results obtained. Each of these stages is described in detail below:

\begin{enumerate}
    \item \textbf{Recreation of the base code} \\
    As a first step, the code presented in \cite{bullinaria2009} will be recreated, which describes the implementation of a multilayer neural network using the \textit{backpropagation} training algorithm in the Python programming language. This code will serve as the basis for the following stages. \\
    In addition, the \textit{Optical Digits} dataset will be used and subjected to a preprocessing procedure to remove invalid records and ensure the quality of the data used in training and validating the model.

    \item \textbf{Extension of the base model} \\
    Subsequently, an extension to the base model will be developed, with the aim of experimenting with more complex configurations of the neural network. Specifically, more than two layers of duplicated weights will be added, which is expected to improve information retention when employing incremental learning. \\
    For this purpose, experiments will be conducted by gradually increasing the number of layers of duplicated weights, in order to analyse the impact of this configuration on the network’s learning capacity.

    \item \textbf{Comparison and analysis of results} \\
    Once the simulation results have been obtained, a comparison will be carried out between the performance of the base model and the extended model. This analysis will include key metrics such as model accuracy, the rate of information forgetting, and performance in incremental learning. \\
    The results will make it possible to assess whether the modifications introduced into the neural network architecture significantly improve its performance compared with the original implementation.
\end{enumerate}
