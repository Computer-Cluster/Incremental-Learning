\section{Objectives}
    \subsection{General Objective}
        To design an artificial neural network for incremental learning based on the principle of short- and long-term memory, aiming to use more than two layers of duplicated weights for digit recognition, achieving a lower information loss compared with previous works.
    \subsection{Specific Objectives}
        \begin{enumerate}
            \item Implement the algorithm presented in \cite{bullinaria2009} for digit recognition through short- and long-term learning, using the parameters indicated therein.
            \item Obtain the Optical Digits dataset, clean the data, and prepare it according to the procedure described in \cite{bullinaria2009}.
            \item Split the dataset into training and testing subsets as explained in \cite{bullinaria2009}, and test the first implemented code to verify the results previously reported in \cite{bullinaria2009}.
            \item Use the implemented algorithm as a basis and extend it to allow more than two duplicated weights, applying the previously mentioned dataset.
            \item Compare both implementations in search of a significant reduction in learning rates with respect to previous works reported in the literature.
        \end{enumerate}
