\section{Consequences}

If the experiment is successful, the following consequences are expected:
\begin{enumerate}
    \item The forgetting of previously learned information will be reduced.
    \item The learning time will be shorter.
\end{enumerate}

As mentioned previously, it will be possible to incorporate new data without the need to retrain the model with all the existing information. \\

Classification or prediction tasks will be able to integrate new information into artificial neural networks without having to retrain the model with all historical data, thus reducing the bottleneck associated with the training process.
